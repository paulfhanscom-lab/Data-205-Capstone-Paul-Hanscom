# Analysis
## Explanation
I first loaded the data. I then created a new dataframe containing the average rainfall across stations and Total number of crashes for a given day. I then created a correlation plot between the two variables. I log scaled the percipitation variable to make the graph easier to read. See EDA doc for distribution of percipitation variables. I then conducted a correlation test with the null hypothesis that their is no corelation. I got a p-value of 0.13 meaning their is no statstically signifigant evidence of correlation between average rainfall across montgomery county and number of car crashes. this does not take into acount spatial data though.
